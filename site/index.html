Team chat you can run from a single binary.

rslack is a self-hosted, Slack-style chat app. Channels, DMs, threads, reactions, search and file uploads all live in one ~7 MB Rust executable with a single SQLite file. No Postgres, no Redis, no Node.

Everything a small team needs

Each feature here was used in a real two-user browser run, which is also where the screenshots on this page come from.

⚡ Realtime

WebSocket fan-out for new, edited and deleted messages, reactions, thread replies, typing indicators and online status.

# Channels & DMs

Public and invite-only private channels, plus 1:1 direct messages. Private channels stay invisible to people outside them.

🧵 Threads

Reply to any message in a side panel. Parents show the reply count and when the last reply came in.

🎉 Reactions

One-click emoji reactions that toggle per user and sync instantly to everyone in the channel.

🔎 Full-text search

SQLite FTS5 with prefix matching. Results only include channels you can read, and user input is quoted so search syntax can't be injected.

🔴 Unreads & mentions

Per-channel unread and mention badges, a "New" marker at your first unread message, and @mention autocomplete with highlighting.

📎 Uploads

Drag, drop or paste files. Images show inline, downloads are access-checked, and there's a size limit.

🔐 Sane auth

argon2id passwords, hashed session tokens in HttpOnly cookies, and WebSocket origin checks.

🌗 Dark & light

Follows your OS theme and can be toggled. Plain HTML, CSS and JS embedded in the binary, with no build step.

Quickstart

From source

git clone https://github.com/shubhxho/rslack
cd rslack
cargo build --release
./target/release/rslack
# → http://127.0.0.1:8080, data in ./data

Create an account, create a workspace, and share its invite code with your team.

Configuration

RSLACK_HOSTbind address (127.0.0.1)
RSLACK_PORTport (8080)
RSLACK_DATA_DIRSQLite + uploads (./data)
RSLACK_MAX_UPLOAD_MBper-file limit (10)
RSLACK_SECURE_COOKIEStrue behind HTTPS
RSLACK_ALLOW_SIGNUPfalse to close sign-ups
RSLACK_PUBLIC_ORIGINpublic URL for proxies that rewrite Host

Every option is also a CLI flag, e.g. rslack --port 9000 --data-dir /srv/rslack.

Docker

docker compose up -d
# → http://localhost:8080
# data persists in the rslack-data volume

The repo includes a two-stage Dockerfile that ends in a non-root Debian slim image, plus a docker-compose.yml with every setting documented. A Hugging Face Docker Space bundle (port 7860, /data with a /tmp fallback) is ready too.

How it works

Every write goes the same way: a REST handler checks your access, commits to SQLite, and then hands a JSON event to an in-process hub. The hub pushes it to every open socket of the channel's members. Nothing reaches a client before it's persisted, and a client that reconnects simply re-fetches.

Browser→axum REST→SQLite (WAL + FTS5)→Hub→WebSocket→Browsers
